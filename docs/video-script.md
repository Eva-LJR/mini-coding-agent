# 两分钟演示脚本

## 录制前

1. 确认 `.env` 已配置且没有出现在 Git 状态中。
2. 确认 `demo_workspace/calculator.py` 中 `add` 函数仍故意使用减法。
3. 先运行项目自身测试，确保 Agent 核心逻辑通过。
4. 调大终端字体，隐藏通知和任何可能出现密钥的窗口。

## 建议口述与画面

**0:00-0:15 项目介绍**

“这是我从零实现的命令行 Coding Agent，没有使用任何 Agent 框架。核心由模型客户端、Agent 循环和本地工具三部分组成。”

画面快速展示项目结构。

**0:15-0:30 核心原理**

“模型通过原生 tool calling 决定下一步；我的程序验证并执行文件或命令工具，再把真实结果放回对话历史，模型据此继续决策。”

画面展示 `agent.py` 中循环以及 `tools.py` 的工具名，不需要逐行讲代码。

**0:30-1:35 真实任务**

运行：

```bash
python main.py --workspace ./demo_workspace --yes --task "运行测试，定位并修复错误，确保全部测试通过"
```

让画面完整显示 Agent 列出/读取文件、运行测试、修改代码、再次运行测试。等待时可说明：“每一次工具调用和结果都显示在终端中，因此可以观察决策过程。”

**1:35-1:50 结果检查**

展示最终测试通过，再打开修复后的 `calculator.py`。

“Agent 根据第一次测试报错定位到加法函数，完成局部修改，并通过第二次测试验证，而不是只生成一段未经运行的代码。”

**1:50-2:00 安全与结束**

“实现还包含路径越界保护、命令确认、超时、最大轮数和敏感环境变量清理。以上是完整演示。”

不要加速到看不清关键调用；如果模型响应较慢，可剪掉中间纯等待部分。
